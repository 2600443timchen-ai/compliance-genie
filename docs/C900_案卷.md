# 金融消費爭議案件卷宗：C900

## 案件基本資料
- **案號**：C900
- **當事人**：一般客戶
- **案件類型**：保險業 - 高風險投資型保單 (適合度評估爭議;KYC義務爭議)
- **爭議標的**：業務員銷售高風險投資型保單未進行風險承受度評估爭議
- **涉案金額**：NT$ 1,850,000
- **申請日期**：115.08.05
- **目前狀態**：申訴受理中，尚未進入評議程序（未裁決）

---

## 爭議事實與要點摘要
1. **事實摘要**：
   - 保戶主張業務員於銷售本投資型保單時，未依規定進行客戶風險承受度評估（KYC），亦未說明商品連結標的之市場風險，僅口頭表示商品「穩健保本」。
   - 保戶於保單價值大幅虧損後，始察覺未曾簽署任何適合度評估文件；保險公司已受理申訴，惟尚未召開評議會議，最終責任歸屬待評議程序確認。
   - 同一分公司先前已有其他保戶提出類似申訴，惟尚未確認是否為系統性問題。
2. **來源文件**：申訴案號 IF115080520（尚未召開評議會議，無評議書文號）
3. **關鍵字**：投資型保單;適合度評估;KYC;風險承受度;說明義務;金融消保法;受理中;未裁決

## 合規精靈評估意見 (Compliance Assessment)
本案重點在於**業務員是否已依規定進行適合度評估與風險揭露**：
1. 若業務員確實未進行風險承受度評估且未留存紀錄，將與同類型案件（高齡客戶適合度評估及KYC義務爭議、投資型保單說明義務爭議）之關鍵事實高度相似，可作為責任分配之參考基礎。
2. 案件仍待評議程序確認最終責任比例，惟同態樣案件多數已有明確評議結果可供類比。
3. **改善建議**：待證據齊備（適合度評估紀錄、業務員教育訓練與稽核紀錄）後，再行後續適法性與理賠評估。
